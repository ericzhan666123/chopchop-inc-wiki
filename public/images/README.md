# Homepage image slots

The homepage works without these files and displays themed color placeholders until they are added.

| File | Recommended size | Use |
|---|---:|---|
| `hero.jpg` | 1600×900 | Main gameplay image in the hero |
| `step-cut.jpg` | 800×500 | Cutting a tree / collecting logs |
| `step-process.jpg` | 800×500 | Processing wood into planks and beams |
| `step-craft.jpg` | 800×500 | Crafting or assembling furniture |
| `step-distribute.jpg` | 800×500 | Drone delivery to the city |

Use optimized JPG or WebP images with the subject centered and enough contrast for a dark interface.
